# DOCX 文件合并工具

一款带有图形界面的 Windows 桌面应用，用于将多个 Word (.docx) 文档合并为一个文件。

## 功能特性

- **文件合并** — 将多个 `.docx` 文件合并为一个文档
- **拖放支持** — 直接拖放文件或文件夹到窗口中
- **文件夹导入** — 一键导入整个文件夹中的所有 Word 文档
- **顺序调整** — 支持上移/下移调整合并顺序
- **图片压缩** — 自动压缩文档中的图片以减小文件体积
- **分页控制** — 可选在每个文件之间插入分页符
- **体积限制** — 合并后文件若超过 10MB 会自动提醒
- **进度显示** — 合并过程中显示实时进度

## 使用方法

### 方式一：直接运行 exe（推荐）

1. 下载 `DOCX文件合并工具.exe`
2. 双击运行
3. 添加文件或文件夹
4. 调整合并设置
5. 点击"开始合并"

### 方式二：从源码运行

```bash
# 安装依赖
pip install -r requirements.txt

# 运行程序
python docx_merger.py
```

### 方式三：自行打包 exe

```bash
# 安装依赖
pip install -r requirements.txt

# 方法 A: 使用构建脚本
python build_exe.py

# 方法 B: 使用 spec 文件
pyinstaller docx_merger.spec

# 生成的 exe 位于 dist/ 目录
```

## 压缩设置说明

| 设置 | 默认值 | 说明 |
|------|--------|------|
| 图片质量 | 60% | 越低压缩率越高，但图片越模糊 |
| 最大尺寸 | 1200px | 超过此尺寸的图片会被等比缩小 |

## 技术栈

- Python 3.10+
- PyQt5 — GUI 框架
- python-docx — Word 文档处理
- Pillow — 图片压缩
- PyInstaller — exe 打包

## 注意事项

- 仅支持 `.docx` 格式，不支持旧版 `.doc` 格式
- 如有 `.doc` 文件，请先用 Word 或 WPS 转换为 `.docx`
- 合并后文件超过 10MB 时会弹出警告，建议删减内容后重试
